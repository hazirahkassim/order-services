What I Built
A responsive web application designed for Admin and Technician roles to manage tasks effectively. The front end is built using React.js with Material UI components for styling, and the back end leverages Firebase Firestore for real-time data storage.

Technologies Used
React.js (Front-end framework)

Material UI (CSS framework for UI components)

Firebase Firestore (NoSQL cloud database)

Firebase Authentication (for login management, partially implemented)

Firebase Storage (intended for image uploads, work in progress)

Challenges Faced
Unable to complete the image upload functionality using Firebase Storage due to limited experience.

Limited knowledge and implementation of Firebase Authentication for the login page.

Faced some difficulties integrating Firebase services with React.
